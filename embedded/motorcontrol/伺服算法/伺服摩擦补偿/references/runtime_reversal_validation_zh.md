# 过零运行、转矩接口与验收

## 输入选择影响过零行为

采用轨迹速度可预知换向，减少测量噪声引起的符号抖动，但实际失跟或堵转时可能提前施加错误方向转矩；采用测量速度更贴近实际，但量化和迟延容易导致抖振。可使用经过验证的速度估计、轨迹意图和状态条件选择，不用一个无迟滞sign函数覆盖所有工况。

平滑宽度 $\omega_\epsilon$ 决定过零补偿的斜率，近零处约为 $F_s/\omega_\epsilon+B_v$。应结合编码器低速噪声、期望换向速度和允许电流变化选择。例 $F_s=0.04$ N·m、$\omega_\epsilon=0.5$ rad/s，对零速附近仅Stribeck项的斜率约0.08 N·m/(rad/s)；这只是量纲与敏感性示例。

## 算法接口

输入：同轴机械速度/轨迹意图、温度/方向调度、可信度、使能状态、$T_s$和模型版本。输出：$\tau_{f,model}$ N·m、有效位、所用方向/温度区间、超出标定范围标志；可另给一阶残差统计。摩擦模块不直接写PWM，也不自行将转矩转换为Iq或叠加到驱动总命令。

合成器 [伺服转矩前馈](../../伺服转矩前馈/GUIDE.md) 统一处理惯量、重力、摩擦、齿槽和观测残差，并对总转矩/电流及斜率限幅。不要一处加入摩擦查表，另一处DOB又加入同一全额摩擦估计。总饱和状态反馈给速度环抗饱和。

使能/禁用使用可追溯的渐入系数，避免小速恒定动作突然跳变；反馈失效或温度模型越界时输出无效/受限候选并让合成器按既定退化策略处理。停车保持、抱闸和静摩擦预载属于更高层状态，不能仅靠本平滑模型决定。

## 对照验证

先使用同一数据离线回放，再在同一动作下对比关闭/开启补偿。测试低速恒速、正反转、微小位移、重复换向、不同温度与预载；记录位置/速度误差、实际转矩/电流、模型输出、饱和及方向状态。

| 表现 | 优先排查 |
|---|---|
| 零速啸叫或抖振 | sign噪声、过小平滑宽度、过量补偿、速度估算延迟 |
| 某位置重复误差 | 齿槽、编码器周期误差、重力或传动周期项 |
| 温升后过补偿 | 温度/润滑变化，标定范围外运行 |
| 加速时误差仍大 | 惯量/加速度前馈、执行饱和，非恒速摩擦拟合问题 |

验证指标由目标给出；补偿后跟随误差减小不等于真实摩擦参数辨识准确。保留工况和重复性，板测前不得写“已消除爬行”。

[Beckhoff换向摩擦说明](https://infosys.beckhoff.com/content/1033/tf5200_friction_comp/352387467.html)讨论换向电流变化，[摩擦参数化](https://infosys.beckhoff.com/content/1033/tf5200_friction_comp/352391819.html)提供速度表及建立/衰减参数背景；本接口不沿用其驱动内部单位。
