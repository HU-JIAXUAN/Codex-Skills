# 伺服自动整定

默认使用中文。先读取任务相关资料，按需加载参考；不将未实测候选写成产品已验证能力。

## Skill 类型

`reusable-domain-knowledge`、`team-expertise`。本技能保存可复用模型、设计判断与验证方法。

## 使用方式

1. 接收由 aicoding-servo-frequency-response 产生的模型/复数FRF、可信频段与方差，或读取已有验证模型；数据不充分时先输出缺口和可执行测量要求。
2. 按结构综合参考生成带单位的基线参数；搜索范围、裕度、噪声与控制量限制来自项目验收，不预填行业通用值。
3. 按运行状态和回退参考筛除低质量识别、超限和模型外推，保存候选参数与基线的可审查差异；需要抑振时让 aicoding-servo-vibration-suppression 设计并联测。
4. 报告数据质量、候选结构/参数、约束是否满足、仿真与板测证据及失败回退，不以自动整定界面显示完成替代产品验收。

## 按需参考

- [从可信模型综合候选参数](references/synthesis_and_search_zh.md)：模型、成立条件与常用设计。
- [整定的运行状态、回退和验收](references/state_machine_and_acceptance_zh.md)：运行接口、失败表现和可观察验证。

## 组合与输出边界

本技能综合增益和候选配置；频响质量不合格时返回识别要求。滤波器设计由抑振技能负责，产品验收由性能验证技能负责，不把自动生成参数等同于已完成实机整定。

与其他算法组合时，按名称定位 `aicoding-motor-control` 的 `references/control_contracts_zh.md`，核对单位、坐标、时间戳、总限幅、状态与证据等级。当前环境缺该参考时，先显式写清本任务对应契约，不依赖跨技能相对路径。涉及C实现结合C99技能，涉及数值与滤波实现结合DSP技能。
