# 伺服指标与对照试验

## 产品指标

| 指标 | 定义与必须说明的条件 |
|---|---|
| 跟随误差 | $e=q_r-q$，峰值、样本RMS或时间加权RMS；明确轴侧、轨迹、计算窗口 |
| 停稳时间 | 指定运动/阶跃起点后，进入误差带并在后续记录中保持，且有足够保持时间；记录长度和采样分辨率 |
| 低速纹波 | 速度/电流/转矩纹波及频带；明确平均速度、温度、负载、机械与电气阶次 |
| 抗扰 | 规定负载注入后的峰值误差、恢复和电流；明确扰动施加位置 |
| 频响 | 输入输出、注入点、幅值、频段、相干性、带宽/裕度/共振 |
| 电流与效率 | 峰值/RMS电流、限制时间、输入/输出功率与热稳态；不将MTPA等同系统效率最优 |
| 资源与一致性 | 最坏执行时间、抖动、内存、标定时间、不同负载/温度/样机结果 |

非等间隔数据同时报告样本RMS和时间加权结果：

$$
e_{rms,t}=\sqrt{\frac{\int_{t_0}^{t_1}e(t)^2dt}{t_1-t_0}}
$$

离散后处理采用梯形积分并注明近似。不能拿不同窗口或滤波后的数据进行无说明对比。实际转矩纹波需可信转矩测量；电流只能作为相应模型下的代理量。

## 试验选择与失败

先使用独立真值/留出数据检验算法，再使用含延迟、限制和参数差异的对象检验闭环。正常、边界、失效/恢复三类场景均选择与改动相关项。观察最终duty和积分，避免把始终限流的快响应当作动态改善。

改进必须同时看目标指标和代价：前馈降低误差可能提高峰值电流，陷波可能损失相位，观测器提高带宽可能增加噪声。将产品阈值和收益/成本并列记录。

来源：[Kollmorgen性能整定与运动验证](https://webhelp.kollmorgen.com/akd2g/english/content/AKD2G_User_Manual/Autotuner.htm)支持频响后检查实际运动停稳与超调；其特定产品的推荐值不能直接当作通用伺服门槛。
