# 激励发生器与采集接入

## 可复用实现

算法资产位于外部CodingKit的`modules/common/controller/Signal generator`。由当前项目已批准的资产发现/依赖入口定位，读取该目录README及`signal_gen.h`确认实际接口；技能不依赖某台电脑路径，也不复制模块为第二份源。没有该资产时按下述契约实现最小所需波形。

将波形、对象和实验状态分开：发生器只产生有确定时间含义的数值；应用拥有注入点、物理约束、记录和停止。位置轨迹规划器承担目标边界状态与运动约束，周期梯形波不自动具有S曲线重规划能力。

使用`SignalGenConfig`填写参数，`SignalGen`保存一路波形的进度。先用`signal_gen_defaults(periodS)`设置调用周期，再填写波形/幅值/频率，调用`signal_gen_init`。周期中`signal_gen_update(&generator, enable)`直接返回波形值；需要记录时读取`generator.currentFrequencyHz/elapsedS/phaseCycles`。返回的波形可以为负，不能用它判断错误；错误看`generator.status<0`，结束看`generator.finished`或`status==SIGNAL_GEN_DONE`。

初始化片段（变量放在所属实例生命周期中，实际调用和限幅由项目组织）：

```c
SignalGen generator;
SignalGenConfig cfg = signal_gen_defaults(0.001); /* 1 kHz */
cfg.wave = SIGNAL_GEN_CHIRP_LOG;
cfg.chirp = (SignalGenChirp){2.0, 200.0};
cfg.durationS = 5.0;
cfg.fadeInS = 0.2;
cfg.fadeOutS = 0.2;
cfg.amplitude = 0.01; /* 例如转矩注入的峰值上界 N*m，须按实际轴确定 */
SignalGenStatus status = signal_gen_init(&generator, &cfg);
```

周期中直接使用`output = signal_gen_update(&generator, enable)`。暂停和结束时返回`offset`；额外扰动通常设置`offset=0`，绝对给定则按偏置和启停安排使用。正常状态为`generator.status==SIGNAL_GEN_OK`。可编译的完整CSV示例和11类参数详见资产目录`examples/minimal_example.c`与README。本模块噪声是均匀伪随机刷新保持，不自带指定带通滤波；需要带限噪声时单独设计并记录滤波器。

## 发生器契约

每个实例独立持有相位、时钟、随机/PRBS状态、配置与完成状态；不使用共享static相位。先检查新参数，正确才替换；参数有错时继续保留原来的设置。不在ISR内分配内存、修改全局随机种子、访问外设或写文件。

| 项目 | 需要明确的语义 |
|---|---|
| 采样时间 | 固定`dt_s`或显式每步dt，哪个调用产生t=0，先输出还是先更新 |
| 频率 | Hz代表完整周期；线性/对数扫频的起止、持续时间与相位积分 |
| 幅值/偏置 | 幅值是半峰峰值、RMS还是其他；多正弦峰值预算不等于单音幅值 |
| 使能 | 停用输出、时钟是否冻结、再使能从哪一状态继续 |
| reset/cfg | 相位、时钟、PRBS及随机种子如何回到可重复初态 |
| 结束 | 有限时长后返回偏置、保持末值还是周期重启；状态由应用消费 |
| 异常 | 非有限数、dt≤0、非法占空比/频带/抽头/空数组应拒绝 |

自然结束或停用返回偏置可能产生阶跃。若波形直接作绝对位置/速度参考，应用应使用停机轨迹或包络渐消；小信号加性注入也需评估中断阶跃。接口的“disable”不等于电机已停稳。

多正弦的系数应复制到实例容量内或声明生命周期，避免配置指向短命栈内存；上限容量有助于WCET可计量。对数扫频和三角函数代价按目标测量，宿主通过不代表10μs ISR满足deadline。

## 接入求和点

```text
实验管理器：验证工况 → 复位/发布配置 → 允许注入 → 采集 → 接受/拒绝
                            ↓
发生器（按约定周期） → 小信号注入 → 统一总限幅 → 控制/调制 → 实际对象
                            ↓             ↓              ↓
记录：计划输入、总请求、最终可实现输入、反馈、时刻、限幅与有效状态
```

不要在转矩前馈和DOB两个位置重复加入同一信号；不要只记录外加正弦而漏记控制器的反馈输出。估计R/L时要求电压与电流对应同一采样/生效区间；扫频测速度时保存速度估计器/滤波器是否属于被辨识对象。

示例配置（数值需按实际轴缩放）：稳定速度闭环下，在转矩求和点加入零均值多正弦；采样1kHz，公共周期2s，选择10、20、40、80Hz等栅格频点。给所有音调分配总转矩峰值预算，再按转矩→电流、速度/行程响应和共振设置更小起点。2s/1kHz只是示范数据契约，不保证某台设备的安全幅值、足够稳态或可辨识性。

## 工程检查

- 数值：固定种子可复现、两个实例互不影响；t=0/暂停/复位/结束与README一致；频率/相位连续且有限；非法配置不改变旧状态。
- 信号：实际样本的DC、RMS、峰值、频率/扫频相位、PRBS周期、多正弦频线与配置相符；未发生非预期削顶。
- 对象：分辨力/过渡、噪声、限幅、温度/行程、相干性与信息量合格；独立数据还能复现模型结论。
- 移植：仅依赖声明的C99数学/整数库；目标可替换数学函数；测实际栈/CPU和最坏路径，不能由GCC宿主结果推断目标实时性。

与传统参考实现相比，应主动核查“freq是否真为Hz”“相位溢出是否丢小数”“disable是否隐藏复位”“函数内static是否串轴”“输出整型转换是否损失小激励”。这些是审查问题，不预先假设开源或现成工程一定正确。
