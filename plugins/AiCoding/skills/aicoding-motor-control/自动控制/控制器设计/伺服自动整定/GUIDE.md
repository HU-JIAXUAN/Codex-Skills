# 伺服自动整定

本文件是[电机控制与伺服总入口](../../../SKILL.md)调度的内部专题指南，不独立注册。`aicoding-servo-auto-tuning` 是内部能力键；其他专题通过[skillkit.json](../../../skillkit.json)的 `target → source/entrypoint` 定位并读取对应 `GUIDE.md`，不调用同名独立 skill。
共同约束读取[公共控制契约](../../../references/control_contracts_zh.md)，执行与证据读取[工程执行契约](../../../references/engineering_execution_zh.md)。

默认使用中文。先读取任务相关资料，按需加载参考；不将未实测候选写成产品已验证能力。

## Skill 类型

`reusable-domain-knowledge`、`team-expertise`。本技能保存可复用模型、设计判断与验证方法。

## 使用方式

1. 接收由 [伺服频响辨识](../../../系统辨识/伺服频响辨识/GUIDE.md) 产生的模型/复数FRF、可信频段与方差，或读取已有验证模型；数据不充分时先输出缺口和可执行测量要求。
2. 按结构综合参考生成带单位的基线参数；搜索范围、裕度、噪声与控制量限制来自项目验收，不预填行业通用值。
3. 按运行状态和回退参考筛除低质量识别、超限和模型外推，保存候选参数与基线的可审查差异；需要抑振时让 [伺服振动抑制](../../补偿与观测/伺服振动抑制/GUIDE.md) 设计并联测。
4. 报告数据质量、候选结构/参数、约束是否满足、仿真与板测证据及失败回退，不以自动整定界面显示完成替代产品验收。

## 按需参考

- [从可信模型综合候选参数](references/synthesis_and_search_zh.md)：模型、成立条件与常用设计。
- [整定的运行状态、回退和验收](references/state_machine_and_acceptance_zh.md)：运行接口、失败表现和可观察验证。

## 组合与输出边界

本技能综合增益和候选配置；频响质量不合格时返回识别要求。滤波器设计由抑振技能负责，产品验收由性能验证技能负责，不把自动生成参数等同于已完成实机整定。

与其他算法组合时，读取[公共控制契约](../../../references/control_contracts_zh.md)，核对单位、坐标、时间戳、总限幅、状态与证据等级。公共参考缺失时报告打包不完整，不能省略本任务的单位、时刻与限制契约。涉及C实现结合C99技能，涉及数值与滤波实现结合DSP技能。

## 可执行工程入口

读取[工程执行契约与能力映射](../../../references/engineering_execution_zh.md)，只加载本专项映射和 L1—L7 验收条件；通过批准的资产发现协议定位 CodingKit，命令与覆盖范围以唯一资产的 README、头文件和实际测试输出为准。

使用 `mc_pi_design` 生成可复算基线，`mc_frf` 提供受限的离线单频幅相。完整搜索、质量筛除与回退整定器尚需实现；禁止将一个基线增益计算函数称为实机自动整定通过。
