# 从频域指标到可执行的环路

## 对象和设计路线

电流环使用dq线性化、增量电感和实际电压误差；速度环使用电流闭环、转矩常数和机械对象；位置环使用速度闭环与运动学积分。把内环当1之前，检查它在外环候选交越附近的幅相。一个固定“三环带宽比例”不能替代这个检查。

例如转矩物理内环$T_\tau$、机械对象$P_m$与测速链$H_\omega$组成$L_\omega=C_\omega T_\tau P_mH_\omega$，实际速度闭环为$C_\omega T_\tau P_m/(1+L_\omega)$。真实负载转矩绕过电流内环、在机械对象输入进入，其速度响应为$-P_m/(1+L_\omega)$；不能与转矩请求处扰动的$-T_\tau P_m/(1+L_\omega)$混用，正负号还应按实际求和点定义。

| 对象/目标 | 合理起点 | 必须挑战的前提 |
|---|---|---|
| RL电流对象、基速内、小信号 | PI零点对准`R/L`，再按延迟选交越 | 温度、增量L、dq耦合、母线/反电势余量 |
| 近似刚性转矩→速度 | PI或两自由度PI，包含电流闭环 | 负载惯量、测速滤波、机械模态、静摩擦 |
| 速度→位置 | P起步，必要时位置PI或2DOF | 真正的速度闭环、回差、量化、外部给定同步 |
| 柔性机械/共振 | 降交越或测后选陷波/主动阻尼 | 模态漂移、非共点测量、陷波引入相位 |
| 延迟主导/模型变化大 | 降低交越、改善时序或改结构 | “加增益即可更快”会耗尽裕度 |

采用loop shaping时，把低频误差/扰动指标转成`S`要求，把高频噪声/建模误差转成`T`和执行器要求；在穿越与共振区域折中。不要用高阶补偿掩盖错误极对数、反相或错误延迟。

## 一条可复算的电流环示例

设连续对象`P=1/(Ls+R)`，`R=0.4Ω`、`L=0.8mH`；并联PI：

$$
C(s)=K_p+\frac{K_i}{s},\quad K_p=Lω_c,\quad K_i=Rω_c.
$$

这来自理想极零消去后`L(s)=ω_c/s`，要求`K_i/K_p=R/L`。若候选`f_c=800Hz`，则`K_p≈4.021V/A`，`K_i≈2010.62V/(A·s)`。它只是无延迟标称起点。

若用连续保持器加`T_comp=50μs`、`T_s=50μs`近似，则总相位额外消耗约`360·800·75μs=21.6°`，理想积分环路PM约68.4°。这个75μs只属于声明的模型；真实采样/影子寄存器事件若不同，需要重算。

直接离散路线更适于验实现：令`a=e^{-RT_s/L}`、`b=(1-a)/R`，在“`u[k]`从`k`到`k+1`保持”的定义下：

$$
i[k+1]=a\,i[k]+b\,u[k],\qquad P(z)=\frac{b z^{-1}}{1-a z^{-1}}.
$$

若控制输出额外晚一个完整采样才生效，再乘`z^{-1}`。这里对象本身的`z^{-1}`是递推输入输出关系，不能直接把它误称为额外计算延迟。R趋近零时用极限`b=T_s/L`避免除零。

## PI离散与总输出

后向Euler并联PI：

$$
x_I[k]=x_I[k-1]+K_iT_s e[k],\quad u_0[k]=K_p e[k]+x_I[k].
$$

梯形积分则为`x_I[k]=x_I[k-1]+K_iT_s(e[k]+e[k-1])/2`。两者数值相位不同，系数与频响应使用实际实现。若先用旧积分算输出再更新，则控制器传递函数也不同。不要只看到“PI”二字就套公式。

dq解耦/反电势FF后经过电压矢量约束、调制、死区及最小脉宽，最终实际可实现量应回传给抗饱和；积分修正的评价点必须与未限幅PI同一坐标、同一拍。电压限幅、速度给定限幅、转矩限幅分别由真实求和点的所有者负责。

前馈可改善跟踪，但一般不增加反馈环本身的稳定裕度；参考预滤波可改变闭环跟踪带宽而不改变`L`。报告时说明究竟改了什么。

## 代码和复算接口

保留既有PI、滤波、坐标变换模块；输入包含有效反馈、`dt_s`/样本时刻、参考、前馈、限幅与使能。输出包含命令、实际可实现量、饱和与状态。系数发布和复位规则独立于ISR求解；不在快环动态分配或每拍重新设计系数。

有Control System Toolbox时可用下面的可改例子检查实际离散式；这里的后向Euler与前述更新次序一致：

```matlab
Ts = 50e-6; R = 0.4; L = 0.8e-3; wc = 2*pi*800;
z = tf('z',Ts);
a = exp(-R*Ts/L); b = -expm1(-R*Ts/L)/R;
P = b/(z-a);
C = L*wc + R*wc*Ts/(1-1/z);
extraDelaySamples = 1; % 从真实时序填写
Loop = C*P/z^extraDelaySamples;
Margins = allmargin(Loop);
Closed = feedback(Loop,1);
stable = isstable(Closed);
bandwidthHz = bandwidth(Closed)/(2*pi);
```

工具不可用时，按同一离散表达式在`z=e^{jωT_s}`上扫复数响应；必要时用特征多项式求闭环极点。有限频网格插值只给数值估计，不能替代全平面稳定性判断。

## 最小工程检查

先用低幅值、无饱和数据确认模型和时序，再看连续/离散预测差异；高转速、低母线、参数变化、负载阶跃和共振漂移检验失配。相同对象与工况下比较跟踪、抗扰、噪声电流、总限幅和恢复。若增加带宽反而恶化停稳，检查模态、噪声和饱和，不强行追求数值更大。

李贵、童维勇《电机控制算法实战》(2024年第1版)书p4–17提供PI、离散、延迟和抗饱和的实际入口；本地核读发现书p12式(1-34)的并联`k_i`印为`R_s/L_s`。按书p5式(1-9)及独立量纲推导，`R/L`应是`K_i/K_p`，并联积分增益为`K_pR/L`。这是一项本地版本公式核对，不能推断所有版次都有同一问题。诸自强、刘侃、梁大为《永磁同步电机参数辨识》书p7–8、41用于区分磁链/电感定义与参数失配，不能把辨识算法本身当闭环稳定性证明。
