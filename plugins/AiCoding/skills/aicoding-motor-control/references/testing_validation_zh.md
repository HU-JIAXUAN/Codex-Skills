# 电机控制测试验证

## 证据与纵向案例

分别记录数学/独立真值、宿主对象、目标构建与时序、实物闭环四类证据。模型结果不替代真实电流、端电压、角度、转矩与温升测量。完整指标设计加载“伺服性能验证”技能 `aicoding-servo-validation`。

三条宿主纵向链：辨识→离散PI→dq解耦；轨迹→速度/转矩前馈→三环；死区补偿→最终调制→抗饱和。外部CodingKit有对应资产时，定位 `examples/servo-validation/README.md` 的当前运行命令和结果；不能仅凭文档认定已通过。
