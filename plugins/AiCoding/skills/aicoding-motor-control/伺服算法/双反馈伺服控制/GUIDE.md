# 双反馈伺服控制

本文件是[电机控制与伺服总入口](../../SKILL.md)调度的内部专题指南，不独立注册。`aicoding-servo-dual-feedback-control` 是内部能力键；其他专题通过[skillkit.json](../../skillkit.json)的 `target → source/entrypoint` 定位并读取对应 `GUIDE.md`，不调用同名独立 skill。
共同约束读取[公共控制契约](../../references/control_contracts_zh.md)，执行与证据读取[工程执行契约](../../references/engineering_execution_zh.md)。

默认使用中文。先读取任务相关资料，按需加载参考；不将未实测候选写成产品已验证能力。

## Skill 类型

`reusable-domain-knowledge`、`team-expertise`。本技能保存可复用模型、设计判断与验证方法。

## 使用方式

1. 确认电机侧/负载侧传感器用途、轴侧、比例、正方向、零位、时间戳和质量；换相位置不得误取未映射的负载编码器。
2. 从两惯量参考识别柔性、惯量折算和不同测点频响；先评估电机侧内速度环与负载侧外位置环基线。
3. 按接口参考处理参考量映射、状态对齐、传动弹性/回差和掉线。需要共振抑制调用 [伺服振动抑制](../../自动控制/补偿与观测/伺服振动抑制/GUIDE.md)，模型来自 [伺服频响辨识](../../系统辨识/伺服频响辨识/GUIDE.md)。
4. 输出反馈结构、模型、坐标转换、控制器候选和故障行为，并同时以电机侧稳定性和负载侧精度验收。

## 按需参考

- [两惯量模型与反馈测点](references/two_inertia_model_zh.md)：模型、成立条件与常用设计。
- [双反馈接口、时延与失效](references/coordinates_delay_faults_zh.md)：运行接口、失败表现和可观察验证。

## 组合与输出边界

本技能负责双反馈控制结构与柔性模型；传感器硬件驱动与零位标定交反馈标定技能，转矩合成交前馈技能。电机侧稳定与负载侧性能分别提供证据。

与其他算法组合时，读取[公共控制契约](../../references/control_contracts_zh.md)，核对单位、坐标、时间戳、总限幅、状态与证据等级。公共参考缺失时报告打包不完整，不能省略本任务的单位、时刻与限制契约。涉及C实现结合C99技能，涉及数值与滤波实现结合DSP技能。

## 可执行工程入口

读取[工程执行契约与能力映射](../../references/engineering_execution_zh.md)，只加载本专项映射和 L1—L7 验收条件；通过批准的资产发现协议定位 CodingKit，命令与覆盖范围以唯一资产的 README、头文件和实际测试输出为准。

调用 `mc_dual_error` 验证传动比/轴侧换算和一致性拒绝。两惯量闭环、回差、负载侧失效与恢复仍需对象模型和目标证据；代数误差函数不构成完整双反馈控制器。
