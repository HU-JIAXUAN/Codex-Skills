# 速度前馈：代码接入与验证

## 接口与顺序

配置含轴侧/尺度、`Ts_s`、无量纲增益、可选滤波带宽和使能过渡时间；状态含滤波记忆、使能权重和上次有效参考。输入是同一参考包的p/v/a及有效性，输出是`velocity_ff_rad_s`、状态和限制原因。

每拍先校验输入有限和参考时基，再更新滤波/使能权重，生成速度前馈；与位置反馈求和后统一限速。位置PI若有积分，跟踪限速后的同一评价点。使能权重从当前值有界变化；停机、回零、模式切换和重规划时按应用语义复位或跟踪状态。

无效参考不继续外推无限时间。应用选择保持/受控停止并明示，算法返回无效原因。配置改变不能令旧滤波状态产生非预期跳变。

## 对照与通过条件

固定轨迹/对象/控制器，分别运行关闭/开启。记录$q_r,v_r,q,v,v_{fb},v_{ff},v_c$、电流、限速和时间戳。对短程、长程、反向、重规划、不同负载和模式切换比较：

- 规定运动段最大/RMS跟随误差以及稳定段噪声；
- 进入指定位置误差带并保持规定时间的停稳时间；
- 峰值/RMS电流与速度/电流限制时间；
- 使能瞬间的速度请求连续性、无效数据处理和最坏执行时间。

速度前馈改善跟踪但不应靠更大峰值电流或换一套增益伪造收益。前馈时间错配常表现为加减速段误差反向、短行程恶化；比例/轴侧错误常表现为方向或幅值相关残差。

模型基线可用一阶速度内环加纯延迟、位置P环和限幅；再在实物相同运动下复核。宿主结果只证明该模型/实现，真实负载和反馈仍需测量。
