# 转矩前馈：实现与验证

## 每拍接口

配置包含轴侧与单位、可信的J/B/模型表及版本、限幅与参数更新规则；输入包含同一参考包p/v/a、负载状态、温度/母线与有效性。输出分项转矩、总转矩、有效标志和限制原因。保留各分项供诊断；运行时不做文件读取或参数表重建。

1. 在统一时基上获取参考与模型，必要时按已测执行延迟对齐。
2. 计算惯量、阻尼、重力、摩擦和已知负载项，每项只由一个模块提供。
3. 与速度控制器输出求和，施加当前可用转矩/电流/热与回馈限制。
4. 用唯一分配器将可行转矩变为id/iq；将同一转矩求和点的限制残差反馈速度积分器。
5. 参数/模式/使能变化采用有界衔接，记录模型版本，不能因热更新直接改变总请求。

若DOB估计总扰动，先定义如何扣除已知模型；若它估计补偿后残差，明确其标称对象与输入。检查闭环是否重复补偿摩擦、重力或惯量。

## 验证

用独立J/负载真值构造对象，模型估计值与真值分开，加入惯量偏差、摩擦、延迟与限流。相同轨迹/增益比较关闭/开启，记录跟随误差、电流、限流占比和停稳时间；分别观察加速、减速、恒速与换向段。

对照包含正反转、不同负载/姿态、母线下降、轨迹加速度不可达、参数更新和无效输入。不可达时应给限制原因并让规划/外环获知，不以持续饱和追踪错误参考。

前馈收益判定同时要求目标误差改善、峰值/RMS电流和噪声代价可接受、解除限幅后恢复。实测轴转矩比较应扣清测量轴侧和传动/机械损耗，不能仅以电流接近理论值作为成功。
