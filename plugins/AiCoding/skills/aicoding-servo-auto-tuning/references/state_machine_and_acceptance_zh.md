# 整定的运行状态、回退和验收

## 让自动整定成为可观察过程

状态可按现有项目组织为准备、数据采集、质量检查、模型拟合、参数综合、离线验证、候选试用和接受/拒绝。每一步记录输入快照、失败原因与结果；并非必须新增一个固定框架。读取数据不自动授权运动、使能或写参数；实机动作仍按当前任务授权和项目机制执行。

区分两种“自动”：离线工具根据已给数据产候选；在线工具在机内激励与修改参数。后者需要明确停机/取消、行程、电流、速度和温度退出条件，保持可恢复的已验证基线，并在超限、失步、CRC/编码器失效或采样异常时结束该次整定。

## 不确定性与模型失效

识别不了惯量时不默认取零；参数取到搜索边界时不宣称最优；模型在多个频段拟合不一致时报告结构缺口。摩擦会污染低频惯量估计，柔性模态会污染高频估计，速度估算滤波会被误拟合成对象阻尼或延迟。

候选仅在其识别负载与反馈配置下成立。变更编码器、速度估算器、采样周期、陷波器、负载惯量或惯量折算后，都要检查原参数契约，不应保留“已整定”标志而跳过验证。

## 参数提交与无扰切换

把整组参数、适用配置和校验结果一起提交，避免速度PI、滤波器和限幅一半新一半旧。使用项目已有影子参数与周期边界机制；使能前检查范围和系数稳定性。对运行中允许的增益切换，按当前实际总输出重建积分状态，并定义滤波器状态的保持、映射或渐变策略。

拒绝候选后恢复已验证配置，不依赖“把新增益乘0.5”作为通用回退。回退也检查状态与命令连续性。

## 验收矩阵

| 对象 | 至少观察什么 | 不能据此直接推断什么 |
|---|---|---|
| 小信号 | 复数FRF、闭环极点、裕度、噪声增益 | 大信号限流后的恢复 |
| 实际轨迹 | 跟随误差峰值/RMS、稳定窗口、超调、电流 | 全部负载/温度均合格 |
| 扰动与饱和 | 负载恢复、积分退饱和、实际输出 | 电气保护已验证 |
| 变工况 | 惯量/姿态/母线/温度、正反转 | 未测试配置可复用 |

阈值来自本产品要求。仿真只说明所用模型下行为，板测补实际时序、执行限制与机械响应；生产接受需项目自己的配置追溯。详尽性能用 aicoding-servo-validation 执行，自动整定输出保留“候选/已接受”的真实状态。
