# C99 主题与设计题干索引

本索引用于按任务选择内部指南，再进入当前问题需要的细节。完整[规则题干索引](rule-topic-index.json)包含 139 个中性条目；稳定 ID 用于检索和复核，不表示存在 139 项自动 lint，也不要求每次任务逐项执行。

## 路由顺序

1. 先识别用户要完成的动作、当前文件操作和真实代码语境，再使用关键词缩小范围。
2. 选择一个主要指南；确有输入、输出、说明或安全方面的缺口时，补读必要的相邻指南。
3. 本次已有规则和合同继续复用；不要因命中多个词，就重复设计已经确定的内容。
4. 指南负责设计推理，检查器负责其实际覆盖的事实。具体表示、阈值和例外服从当前项目，不把题干直接当作无条件的错误判据。

## 最重要的组合路径

### 函数设计与输入输出

先进入函数指南，按“用途和调用者 → 输入/输出/失败 → 数据与资源寿命 → 调用上下文 → 最小实现 → 验证”推进。声明与实现说明使用同一术语、单位和错误含义；需要整理说明时补读注释指南，不能先写漂亮模板再猜代码行为。

可检索题干：`C99-R016` 函数职责、`C99-R021` 输入校验责任、`C99-R022` 失败结果、`C99-R025` 只读输入、`C99-R028` 参数内聚性、`C99-R091` 声明与定义说明、`C99-R118` 可观察输入输出。

### 新建或拆分文件

先进入文件指南确定归属、公开/私有边界与构建接线；存在新的公共接口时再走函数合同，随后按注释和命名指南完成一致呈现。只生成一个私有实现文件，不自动要求增加无实际公开用途的头文件。

可检索题干：`C99-R001` 公开合同、`C99-R003` 依赖方向、`C99-R007` 独立头编译、`C99-R010` 接口声明、`C99-R012` 模块公开入口。

### 写或调整注释

先判断说明对象是文件职责、公共接口使用合同、实现关键原因，还是字段/状态语义。只读懂名称而没有读取实现，不能补造输入范围、失败策略、线程安全或时序保证。统一普通中文块注释外观，按当前项目保留实际文档生成要求。

可检索题干：`C99-R086` 自解释代码、`C99-R088` 关键意图、`C99-R089` 行为同步、`C99-R090` 文件职责、`C99-R091` 接口合同、`C99-R092` 共享状态说明、`C99-R096` 注释一致性。

### 使用语言词与接口名

- `static` 用于函数时先看可见性与链接；用于局部对象时先看寿命、状态与可重入性。
- `const` 先区分对象、指向内容与指针自身；`volatile` 涉及中断或硬件时补读实时指南，不能据此推断同步正确。
- `restrict` 先核对实际别名承诺；`inline` 先核对链接规则与调用成本，不按名称保证一定内联。
- `sizeof` 遇到数组参数、指针或协议长度时补读表达式/安全指南，检查其实际计量对象和单位。
- `size_t`、`uint32_t` 是类型名，`#define` 是预处理指令，`memcpy` 是库函数；均可作为检索线索，但不能混称 C 语言关键字。
- 单词仅出现在字符串、日志或被讨论的说明中，不等于当前实现使用了对应语言机制。
