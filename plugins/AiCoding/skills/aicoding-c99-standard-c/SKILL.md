# C99 工程技能套件

默认简体中文；唯一运行时入口为 `aicoding-c99-standard-c`。本目录的内部指南不是独立注册的 Skill：先加载本入口，再按当前问题读取一至两个主要专题，需要时补充相关细节。

## Skill 类型

属于 `consistent-workflow`、`organization-standard` 和 `team-expertise`：提供按问题选择的设计流程、方法、限制、代码模板及可验证的工程约束。

## 怎么选择内部专题

按“用户当前任务 → 文件操作 → 代码中的具体语境 → 关键词提示”选择。词命中只提供线索，不要求加载所有命中的专题；代码字符串/注释中的单词不能自动当作真实语言使用。已有上下文和适用授权继续复用，不循环转交或反复确认。

例如：新建模块走“文件 → 函数合同 → 注释/排版 → 当前代码需要的专题 → 验证”；只改注释先读真实声明、实现和调用者；`static` 局部状态优先查寿命，`volatile` 设备寄存器优先查硬件语义。`size_t` 是类型名，`#define` 是预处理指令，`memcpy` 是库函数，不能混同语言关键字。

## 所有专题共同遵守的基线

- 先理解用户要的正常、边界与失败行为，读取当前实现、至少一个相关调用者和真实构建入口，再确定最小改动。
- 函数输入、输出、错误、单位、指针寿命与执行上下文必须能解释；注释必须与实际代码一致，不能用模糊术语或空标签替代合同。
- 默认普通简易中文块注释、4 空格、函数 `snake_case`、参数/局部 `lowerCamelCase`、类型 `PascalCase`、120 列；明确项目规则和当前用户要求优先。完整约定见[项目编码基线](references/project-coding-baseline-zh.md)。
- 保留真实编码、BOM、换行、稳定公共接口和生成/第三方边界；不借风格整改扩大重构，不机械引入 manager、线程、动态分配或抽象层。
- 不虚构 SDK API、寄存器位、默认参数、作者/公司/认证、已运行的构建和测试；无关或未执行检查不得写成通过。
- 复杂度数字是设计复核信号。现有语义和有效授权已足够时直接处理，不为保持契约的局部调整新增审批或文档。

## 工作流契约

触发：任何 C/H 编写、修改、评审或规范门禁任务；一次性语法问答可直接路由相关专题，不执行完整工程流程。

输入：当前任务、目标文件和归属、现有接口与调用者、实际编码、项目配置/工具链及必要的硬件和时序约束。

步骤：

1. 识别本次行为与允许变化，选择主要专题并读取需要的细节。
2. 对新增或确需变化的公共契约先形成可审查的接口和失败语义；沿用已有确认，只补会改变方案的缺口。
3. 按项目基线完成最小实现；同时维护文件、函数合同和关键实现原因的注释。
4. 对真实候选与当前配置执行相称的格式、lint、编译、行为或目标验证；内容变化后旧结果失效。
5. 报告实际结果和仍需人工/硬件证据的边界，清理本次临时文件。

完成标准：当前需求与输入输出合同一致，整体风格与注释一致，实际候选通过适用检查，失败/未运行/人工项被明确区分。详细[生成与修改契约](references/generation-contract-zh.md)不要求每次新建表单。

## 门禁规则

- CLI：优先复用项目编译器、formatter、分析器和现有检查器；命令必须绑定真实文件与配置，失败返回非零退出码。具体覆盖见[验证与 Hook](references/verification-and-hooks-zh.md)。
- Codex Hook：项目显式 `.c99-policy.json` 才启用检查与保护路径阻塞；无项目配置只提醒。Hook 调用只读检查，不自动改写、提交、烧录或部署代码；失败不能当作通过。
- Git/CI：独立检查最终提交内容，不能仅依赖会话观察、某次工具成功或注释标签数量。
- 人工：输入输出的语义、职责、单位、寿命、注释准确性、硬件副作用和实时性仍按实际工程复核。缺工具和未实现检查具体报告，不以低可靠性正则冒充语义验证。
- 人工确认：项目负责人选择阻塞命令与保护范围；本次任务已有的有效确认继续复用。
- MCP：当前核心流程不需要新 MCP，使用已有 CLI/构建；可用的项目诊断工具只补充事实，不替代规则裁决。

## 人工反馈确认

确认人是当前用户或项目负责人，当前重点是函数输入输出、文件/函数/关键代码注释及整体一致性。输入输出语义和注释准确性由人工复核。项目具体命令、排除/保护范围采用已确认配置；新增插件 Hook 需通过 `/hooks` 审阅信任后才可报告已启用。源码、生成包与安装运行状态分别报告。

## 输出

先给结果和本次范围，再给必要的接口/实现取舍、实际命令结果及未验证项。小改动复用现有记录，不能把完整流程、全库扫描或新增文档当成通用前提。
