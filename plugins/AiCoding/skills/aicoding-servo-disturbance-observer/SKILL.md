# 伺服扰动观测

默认使用中文。先读取任务相关资料，按需加载参考；不将未实测候选写成产品已验证能力。

## Skill 类型

`reusable-domain-knowledge`、`team-expertise`。本技能保存可复用模型、设计判断与验证方法。

## 使用方式

1. 写出机械状态方程、正方向、输入和扰动单位，确定输出是负载转矩、加速度扰动还是残差；不要先按变量名假定符号。
2. 名义模型可信时读取DOB参考；总扰动状态建模时读取ESO参考。审查传感器噪声、时延、相对阶、柔性模态和离散极点。
3. 使观测器输入匹配实际施加的执行量；与摩擦、重力、齿槽和转矩前馈分工，观测已经补偿后的残余或明确采用独占方案。
4. 输出模型、离散式、状态初始化、增益/带宽候选、限幅/失效行为及可观测对照，调用 aicoding-servo-validation 验证噪声与扰动恢复。

## 按需参考

- [名义模型DOB与负载转矩估计](references/dob_nominal_model_zh.md)：模型、成立条件与常用设计。
- [线性ESO、单位与验证](references/eso_and_validation_zh.md)：运行接口、失败表现和可观察验证。

## 组合与输出边界

本技能输出扰动/残差及补偿候选；不声称观测量可唯一分离摩擦、重力、齿槽和参数误差。所有补偿最终由转矩合成技能处理，保留饱和与失效状态。

与其他算法组合时，按名称定位 `aicoding-motor-control` 的 `references/control_contracts_zh.md`，核对单位、坐标、时间戳、总限幅、状态与证据等级。当前环境缺该参考时，先显式写清本任务对应契约，不依赖跨技能相对路径。涉及C实现结合C99技能，涉及数值与滤波实现结合DSP技能。

## 可执行工程入口

按技能名定位 `aicoding-motor-control` 的 `references/engineering_execution_zh.md`，只加载本专项映射和 L1—L7 验收条件；通过批准的资产发现协议定位 CodingKit，命令与覆盖范围以唯一资产的 README、头文件和实际测试输出为准。

调用 `mc_dob_init/update` 的一阶 Q 精确 ZOH 子集，输入必须是实际施加转矩。完整 ESO、柔性模型 DOB 和含噪目标验证尚需专项实现；不得把总扰动估计称为唯一摩擦参数。
